# ARK Listable - Installation Guide

## 📱 Android Phone Par Install Karne Ka Tarika:

### Method 1: PWA (Progressive Web App) - Recommended ✅
1. Apne phone ke browser (Chrome ya Edge) mein `index.html` file ko kholein
2. Browser ke menu mein jaayein (3 dots)
3. "Add to Home Screen" ya "Install App" option pe click karein
4. App icon home screen par aa jayega
5. Ab ye normal app ki tarah chalega (offline bhi!)

### Method 2: WebAPK (Advanced)
1. PWA install karne ke baad, Chrome automatically WebAPK banaata hai
2. Ye native Android app ki tarah behave karega
3. App drawer mein dikhega aur settings mein manage kar sakte hain
